# Figure provenance

`research_v1/` contains the current study's seven figures, each in PNG and SVG.
They are regenerated by `scripts/make_figures.py` from the saved result tables.
Use SVG for large printed displays.

Images outside that directory belong to the historical analysis. They are
retained for audit, superseded by the current figures, and should not be used as
evidence for the earlier claims about physical-law recovery or weakened braking.
