# Figure provenance

`real_stars_v2/` contains the current follow-up's four figures: distribution scores,
coverage, withheld-cluster ages and external M67 observations. Regenerate them
with `scripts/report_real_stars.py`. All selected external stars and all 16
age-test clusters are shown; no residual-based exclusions are made.

`research_v1/` retains the initial study's seven figures, regenerated by
`scripts/make_figures.py` from the saved result tables. Both studies provide PNG
and SVG; use SVG for large printed displays.

Images outside those directories belong to the historical analysis. They are
retained for audit, superseded by the current figures, and should not be used as
evidence for the earlier claims about physical-law recovery or weakened braking.
