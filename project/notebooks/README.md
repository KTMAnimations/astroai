# Historical exploratory scripts

These scripts and their original outputs document the earlier investigation.
They do not form the supported reproduction pipeline for the current results.
The audit found incomplete result-generation paths and unsupported interpretations,
including the M67 braking claim and using expression stability as proof of truth.

Use `python scripts/run_study.py` from the repository root for the current study,
and `python -m pytest` for its regression and scientific-consistency checks.
The new results live in `project/results/research_v1/` and follow
`docs/PROTOCOL.md`. Historical files outside that directory are not mixed into
the current result tables or figures.
